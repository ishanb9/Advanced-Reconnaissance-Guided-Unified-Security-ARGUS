# ─────────────────────────────────────────────────────────────────────────────
#  ARGUS · Kali system-tool requirements  (the OS-level counterpart to
#  requirements.txt, which only covers the Python packages)
# ─────────────────────────────────────────────────────────────────────────────
#
#  WHY THIS FILE EXISTS
#    ARGUS does not bundle its attack tools — it shells out to the Kali binaries
#    listed in the MCP tool registry (mcp-server.js, "TOOL REGISTRY"). Any tool
#    that registry references MUST exist on the Kali host, or ARGUS returns
#    "Tool not found in MCP" / classifies it tool_missing and stops using it.
#    This file is the canonical inventory of every external binary ARGUS can
#    invoke (356 tools across 23 categories), plus the runtime prerequisites
#    and the wordlists it hardcodes.
#
#  HOW TO INSTALL  (pick one)
#    1. Simplest (recommended on a real Kali box) — the meta-package pulls ~95%:
#           sudo apt update && sudo apt install -y kali-linux-everything seclists
#    2. Granular / minimal-Kali / cloud images — run the bundled installer,
#       which does apt + go + pipx + git + downloads and then VERIFIES every
#       binary in the registry and reports what is still missing:
#           sudo bash install-kali-tools.sh
#    3. Manual — install the categories you need from the lists below; use the
#       "NON-APT" section for the tools that are not in the Kali apt repos.
#
#  VERIFY what ARGUS can actually run at any time:
#           bash install-kali-tools.sh --verify
#
#  NOTE: ARGUS gracefully degrades — a missing tool is skipped, not fatal. But
#  coverage (esp. the OWASP Top 10 web vectors) is only complete when the web
#  tools below are present. Tools flagged ⚠ were observed missing on stock Kali
#  in real runs (install them explicitly).
#
# ═════════════════════════════════════════════════════════════════════════════
#  RUNTIME PREREQUISITES (not pentest tools, but ARGUS will not start without)
# ═════════════════════════════════════════════════════════════════════════════
#   python3        (>= 3.11)                  apt install python3 python3-venv python3-pip pipx
#   node + npm     (>= 18, runs mcp-server.js) apt install nodejs npm
#   metasploit-framework (msfconsole/msfvenom) apt install metasploit-framework
#   seclists       (wordlists, see bottom)     apt install seclists
#   golang         (>= 1.21, for the Go tools) apt install golang-go
#   ollama         (LLM client; scan model deepseek-v3.1:671b-cloud)  https://ollama.com/download
#
