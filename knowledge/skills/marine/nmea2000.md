# NMEA 2000 / CAN backbone

NMEA 2000 (IEC 61162-3) is a **CAN-bus-derived** fieldbus that replaced the older RS-422 NMEA 0183
daisy-chain on modern vessels. It operates at **250 kbps** over a shielded twisted-pair backbone
with a 5-pin circular connector (DeviceNet-compatible). Sensors and actuators — GPS receivers,
AIS transponders, depth sounders, wind instruments, engine monitors, autopilots, and rudder
feedback units — all attach as nodes and exchange typed **Parameter Group Numbers (PGNs)**:
PGN 129025 (Rapid Position Update), PGN 127250 (Vessel Heading), PGN 127488 (Engine Parameters
Fast Update), PGN 128259 (Speed), and PGN 126208 (Command Group Function, the write/command PGN).
Physical access to any backbone T-connector provides passive bus monitoring; USB-to-N2K adapters
(Actisense NGT-1, Yacht Devices YDWG-02) bridge the bus to IP for logging and analysis tools.

**Safety-of-life scope.** NMEA 2000 carries live navigation sensor data to ECDIS, chartplotters,
and autopilots, and in many installations carries propulsion-control messages to engine ECUs and
thruster controllers. PGN 126208 (Command Group Function) can set autopilot heading, adjust
throttle, and command other writable parameters with no authentication requirement — anyone
with physical bus access can issue actuation commands. This is `life_safety: true`. A 2021
NCC Group study demonstrated that NMEA 2000 command injection can override autopilot heading
within milliseconds, with no alert to the officer of the watch.

**Safe-first testing.** All active testing requires physical bus access (T-connector tap or
USB bridge) or a network segment hosting an IP-to-N2K gateway. Begin with passive CAN frame
capture using `candump` or the `canboat` analyzer to enumerate active nodes (NAME fields contain
manufacturer code, class, function, and serial number), transmitted PGNs, and update rates —
all without placing any frames on the bus. Inventory writable PGNs (PGN 126208 targets) and
cross-reference against the installed equipment list. **Do not** place any write frames on
a live bus without explicit scoped authorization, vessel at berth, all propulsion systems
offline, and a human gate at the helm — bus-level command injection has sub-second actuation
latency.

**Remediation.** Physically restrict T-connector access and lock junction boxes; deploy
NMEA 2000 firewalls/gateways (Yacht Devices, Actisense) that filter PGN 126208 writes to
trusted source addresses only; log all bus traffic to a tamper-evident store; and segment
any IP-to-N2K bridge onto a dedicated navigation VLAN. Reference IEC 61162-3 and the NMEA
2000 standard (v3.0) for device address-claim and PGN allocation tables.
