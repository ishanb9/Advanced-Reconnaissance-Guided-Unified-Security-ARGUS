Methodology & CVSS Rubric

Engagement Methodology

ARGUS operates a plan → execute → validate loop over a hypothesis tree. Each action is annotated with a MITRE ATT&CK technique and produces an evidence chain before a finding is recorded.

  • ‣Findings ship only when grounded in concrete tool evidence (ARGUS Issue-Validator gate)
  • ‣Every exploitable path is re-confirmed on a dedicated retest pass
  • ‣Non-exploitable paths are documented as coverage (not omitted)
  • ‣All artifacts are integrity-hashed and stored in the secure evidence store
  • ‣Time-boxed; absence of finding is not proof of absence
